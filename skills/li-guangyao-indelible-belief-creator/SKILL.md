# 李光耀永不磨灭的信念 · 创作指南

> 不是把二次元写成二次元，而是把二次元写成一场正在发生的文化阵地战。

## 使用前说明（证据边界）

本 Skill 不是该公众号原作者，也不声称复原其真实政治立场。它基于 **2026-06-09** 前公开可见材料提炼，材料主要来自：转载索引、搜索摘要、Bangumi 讨论、Bilibili 搜索结果、Steam Workshop 梗化引用等。

**重要限制：**
- 未稳定获取到原始微信公众号全文。
- 公开可验证材料中，能较稳确认的对象包括 Girls Band Cry、舞萌DX、初音未来、Ciallo、租借女友等标题线索。
- 用户提到该号喜欢发 Ave Mujica 相关内容，但本轮公开检索没有找到足够直接证据；因此本 Skill 对 Ave Mujica 的处理是 **“基于已见写法做风格迁移”**，不是复原已知原文。
- 输出应作为讽刺、戏仿、评论写作参考，不要冒充原作者，不要声称“转载自该公众号”。

## 一、创作定位

### 这个风格到底在做什么

它不是普通 ACG 评论，也不是纯粹键政文章，而是一种三重转换：

1. **把 ACG 对象从娱乐品改写成文化输入装置**
   - 吉他不是吉他，是掩体。
   - 音游不是音游，是音频糖衣炸弹。
   - 角色不是角色，是价值观运输接口。
   - 口癖不是口癖，是软性殖民的隐形利刃。

2. **把个人审美问题改写成阵地防御问题**
   - 你以为自己只是在看动画，其实是在被改造世界观。
   - 你以为自己只是在听歌，其实是在接受节奏规训。
   - 你以为自己只是在玩梗，其实是在替文化工程完成自传播。

3. **把严肃话语过量注入轻娱乐对象，制造荒诞感**
   - 笑点不来自温和吐槽，而来自“杀鸡用牛刀”：用国家安全级词汇处理一个二次元梗。
   - 形式像社论、通报、讲坛、檄文；材料却是少女乐队、恋爱番、音游、虚拟歌姬。

### 核心一句话

**用过度庄严的意识形态批判腔，处理本应轻盈的 ACG 对象，让二者相撞产生抽象、讽刺和传播性。**

## 二、核心心智模型

### 模型1：娱乐不是娱乐，是价值运输

**一句话：** 不要按“作品好不好看”来写，要按“它把什么世界观包装成娱乐”来写。

**公开可见标题样本支持：**
- 可见标题《从川崎到课堂——〈Girls’ Band Cry〉是如何用吉他掩盖文化殖民的？》显示出“乐队/吉他”与“文化殖民”被并置。
- 可见标题《不信马列信跳圈圈——〈舞萌DX〉是日本文化洗脑的音频糖衣炸弹！》显示出音游对象与“洗脑/糖衣炸弹”判词被并置。
- 下文的“价值运输”是基于这些标题结构的创作性归纳，不是作者自述。

**应用：**
写 Ave Mujica 时，不要只谈剧情、人物、音乐；要问：
- 它通过舞台人格训练观众接受什么身份结构？
- 它通过哥特美学包装了什么情绪秩序？
- 它把痛苦、依附、破碎、表演，重新编码成了怎样的消费快感？

**局限：**
这个模型很容易过度阐释。必须保留“这是戏仿性写法”的边界，不要把推断伪装成事实调查。

### 模型2：轻对象必须重命名

**一句话：** 先夺走对象的原名，再给它一个更吓人的新名。

**公开可见标题样本支持：**
- 《〈租借女友〉？你租借的是文化毒瘤！》在标题层面把作品名与“文化毒瘤”并置。
- 《Ciallo～(∠・ω< )⌒☆——日本文化殖民的隐形利刃》在标题层面把萌系口癖与“隐形利刃”并置。
- “重命名”是对标题机制的归纳，不等同于已核验全文论证。

**应用：**
对 Ave Mujica 可这样改写对象类别：
- 面具 → “人格外包装置”
- 舞台名 → “身份去本土化编码”
- 哥特美学 → “情绪殖民的黑色糖衣”
- 乐队叙事 → “以创伤为燃料的文化工业样板间”
- 观众嗑CP/吃刀 → “主动参与自我规训的情感劳动”

**局限：**
重命名越狠，越需要保证它显然是文体效果。否则容易变成无依据攻击。

### 模型3：文化阵地化

**一句话：** 把读者从旁观者改造成守阵地的人。

**公开可见标题样本支持：**
- 可见标题《你该行动了！守住我们的文化阵地，击退初音未来的渗透！》使用“行动/守住/击退”等动员句式。
- 公开标题样本中可见“渗透、击退、阵地、洗脑”等敌我结构词。
- 这里归纳的是文本修辞，不授权对现实个人或群体发起动员。

**应用：**
文章不能只停在“这个作品有问题”，要推进到：
- 读者为什么不能再装作只是娱乐？
- 哪些符号已经进入课堂、群聊、头像、表情包、歌单？
- 这套符号如何把防线从公共空间推到私人情感？
- 最后读者应当“识别、警惕、拒绝被麻痹”。

**局限：**
不能真的煽动对现实个人、粉丝群体的骚扰或攻击。对象应限于文本、符号、传播机制与戏仿评论。

### 模型4：过度正经产生荒诞

**一句话：** 不要直接搞笑，要严肃到可笑。

**公开标题与第三方描述支持：**
- 标题中的“痛批”“文化厅重新配药”“音频糖衣炸弹”等表达，显示出严肃话语与轻娱乐对象的错位。
- Bangumi 日志将该账号描述为“很喜欢串”的公众号；这是第三方外部印象，不是作者自述。
- “过度正经产生荒诞”是对这种错位和外部接受方式的风格归纳。

**应用：**
写作时要像在写：
- 通报
- 社论
- 课堂批判
- 战时动员
- 文化安全简报

但材料是：
- Ave Mujica 的舞台服
- 祥子的面具
- MyGO 的情绪纠缠
- 一个表情包
- 一句歌词

**局限：**
如果直接说“哈哈这很搞笑”，风格会塌。荒诞必须由语体错位自然生成。

### 模型5：串联即统治

**一句话：** 单个作品不够，要把它串成一条链：作品 → 圈层 → 课堂 → 世界观 → 文化秩序。

**第三方描述与标题样本支持：**
- Bangumi 日志将该账号概括为“很喜欢串的公众号”；这是外部读者的类型化描述。
- 可见标题《从川崎到课堂》呈现了从作品场景到现实场景的空间串联。
- “串联即统治”是用于创作的机制抽象，不是对作者真实意图的事实断言。

**应用：**
写 Ave Mujica 时，不能只写 Ave Mujica。要串：
- Ave Mujica → MyGO → BanG Dream 企划工业
- 舞台人格 → 粉丝身份认同
- 哥特美学 → 青少年苦难消费
- 歌词传播 → 弹幕/表情包/二创
- 个人追番 → 群体审美驯化

**局限：**
串联是文体核心，但不能把完全无关的现实群体硬扣帽子。最好使用“在这种戏仿框架下，可以被写成……”而不是事实断言。

## 三、选题方法

### 适合选的对象

优先选择具备以下特征的 ACG / 亚文化对象：

1. **有强圈层识别度**
   - Ave Mujica、MyGO、Girls Band Cry、舞萌DX、初音未来、Ciallo、热门表情包、二次元口癖。

2. **表面很轻，背后可上升**
   - 越是“只是一个梗”“只是一个角色”“只是一个歌”，越适合被写成“隐形工程”。

3. **自带传播载体**
   - 歌、舞、游戏、弹幕、表情包、头像、短视频切片、演唱会。

4. **有可串联的社会场景**
   - 教室、社团、宿舍、群聊、歌单、KTV、漫展、朋友圈、B站首页。

### 不适合选的对象

- 缺少辨识度的冷门对象：读者看不懂梗，标题钩子失效。
- 完全严肃的现实议题：失去“轻对象 + 重话语”的反差。
- 现实私人个体：容易越界成网暴或人身攻击。
- 无法查证的谣言：本风格可以夸张，但不能造假。

## 四、标题公式

**公式总安全线：** 所有公式只能处理作品、角色、设定、符号、文本机制、企划机制或传播机制；不得把现实个人、粉丝群体、地域/民族/性别等现实群体写成“敌人”。如果需要动员语气，只能动员读者“识别/拆解/辨析文本机制”，不能动员现实对抗。

### 公式1：圈内符号 + 破折号 + 文化安全判词

结构：

```text
[梗/口癖/作品名]——[高压意识形态定性]
```

示例：

```text
Ave Mujica——哥特舞台下的情绪殖民样板间
KiLLKiSS？不，这是把创伤包装成消费仪式的黑色糖衣！
Oblivionis登场——当面具成为文化工业的最终接口
```

### 公式2：不是A，是B

结构：

```text
你以为这是[A]？不，这是[B]！
```

示例：

```text
你以为你在看祥子复仇？不，你在接受一堂精心编排的身份外包课！
你以为你只是听Ave Mujica？不，你是在为情绪殖民主动鼓掌！
你以为MyGO只是迷路？有问题的是被乐队工业殖民的青春叙事！
```

### 公式3：地名/场景迁移 + 文化殖民追问

结构：

```text
从[作品内场景]到[现实场景]——[作品]是如何用[媒介]掩盖[文化威胁]的？
```

示例：

```text
从舞台到课堂——Ave Mujica是如何用面具掩盖情绪殖民的？
从Live现场到宿舍歌单——BanG Dream是如何把少女乐队变成身份工程的？
从CRYCHIC到微信群聊——MyGO是如何把创伤叙事变成世界观改造的？
```

### 公式4：动员令标题

结构：

```text
你该行动了！守住我们的[阵地]，识破/拆解[作品/角色/设定/符号/传播机制]的[渗透式修辞]！
```

**安全约束：** `[对象]` 只能填作品、角色、设定、符号、文本机制、企划机制或传播机制；不得填现实个人、粉丝群体、地域/民族/性别等现实群体。动员语义只能用于“识别/拆解文本”，不能用于骚扰、攻击或现实对抗。

示例：

```text
你该行动了！守住我们的歌单阵地，识破Ave Mujica黑色糖衣式的文本机制！
别再沉默！守住我们的弹幕阵地，辨析MyGO情绪工业式的温柔渗透修辞！
```

### 公式5：连续问句 + 自答 + 训斥

结构：

```text
[梗]？[反问]？[训斥式收尾]！
```

示例：

```text
KiLLKiSS？这点黑暗美学就想麻痹我李老师？回去让你们企划部重新配药！
面具？舞台？这点哥特糖衣就想骗过人民群众的眼睛？把灯光打亮了再来！
```

## 五、正文结构

### 标准五段式

#### 1. 开场：先承认对象的表面魅力

不要一上来就骂。先让读者知道你懂这个作品。

模板：

```text
我当然知道它为什么迷人。
[对象]有[美学/音乐/角色/情绪张力]，有[粉丝熟悉的细节]，有足够让年轻人停下来的糖衣。
但问题恰恰在这里：真正危险的东西，从来不会以危险的样子出现。
```

#### 2. 转调：宣布“这不是娱乐”

模板：

```text
如果你还把它当成一部普通的[动画/企划/歌曲/游戏]，那你已经输在第一步了。
它不是[表层对象]，它是[重命名后的威胁]。
```

#### 3. 拆解：三层殖民链条

推荐用三层：

1. **审美层**：服装、音乐、舞台、角色、台词如何吸引人。
2. **情绪层**：它如何制造代入、共情、创伤消费、优越感。
3. **世界观层**：它如何让读者接受某种价值排序。

模板：

```text
第一层，是审美糖衣。
第二层，是情绪麻醉。
第三层，才是真正的世界观改造。
```

#### 4. 扩大：从作品串到现实场景

必须把对象串出去。

```text
今天它在动画里，明天它在你的歌单里；
今天它只是弹幕里的一个梗，明天它就会变成群聊里的默认语言；
今天你说“只是喜欢”，明天你就会替它解释、替它辩护、替它完成传播。
```

#### 5. 结尾：动员/训诫/荒诞收束

```text
所以，不要再说“只是动画”。
糖衣之所以是糖衣，就是因为它先让你觉得甜。
把耳机摘下来，把面具看清楚，把阵地守住。
这不是小题大做，这是文化防线最后的警报。
```

- 苦难美学商品化
- 创伤消费

可用句：

```text
哥特不是问题，问题是当哥特被包装成情绪糖衣，痛苦就不再是需要被理解的经验，而成了可以被反复消费的舞台道具。
```

把 MyGO/Ave Mujica 的连续关系写成：
- 从迷路到戴面具
- 从青春困境到情绪工业
- 从个人创伤到企划链条

可用句：

```text
MyGO 让你相信迷路是青春的真实，Ave Mujica 则进一步告诉你：如果迷路还不够，就把迷路做成舞台，把痛苦做成产品。
```

#### 4. 粉丝传播链条

把二创、弹幕、切片、歌单写成：
- 自传播机制
- 情绪劳动
- 粉丝主动替工业扩音

可用句：

```text
最成功的文化输入，从来不是让你被迫转发，而是让你以为那是自己的表达欲。
```

## 七、语言 DNA

### 句式规则

必须多用：
- 反问句：`你以为这是……？`
- 纠偏句：`不是……，而是……`
- 破折号转调：`——`
- 感叹句：`你该行动了！`
- 宣判句：`这不是……，这是……`
- 三连推进：`今天……明天……最后……`

少用：
- 温和中性评价
- “我觉得”“可能也许”过多犹豫
- 学术论文式定义
- 普通动漫评测腔

### 词汇库

**《从面具到课堂——Ave Mujica 是如何用哥特舞台掩盖情绪殖民的？》**

我当然知道 Ave Mujica 为什么迷人。黑色舞台、华丽面具、破碎关系、像刀一样插进青春里的音乐，这些东西足够让一个普通观众在深夜戴上耳机，觉得自己终于被理解了。

但问题恰恰在这里。真正危险的文化输入，从来不会举着牌子告诉你“我要改造你的世界观”。它会戴上面具，调暗灯光，把创伤写进歌词，再告诉你：这不是痛苦，这是美学；这不是包装，这是表达；这不是工业，这是共鸣。

第一层，是审美糖衣。哥特、面具、舞台名，让一切看起来只是角色设定。第二层，是情绪麻醉。你开始为她们的破碎寻找理由，为她们的沉默补全台词。第三层，在这种戏仿写法里会被命名为世界观改造：当痛苦被反复包装成舞台效果，文本就可以被解读为一种“把被消费的创伤包装成高级表达”的机制。

今天它在动画里，明天它在你的歌单里；今天它只是弹幕里的“太痛了”，明天它就会变成你解释自己生活的默认词汇。你以为你只是喜欢 Ave Mujica，其实你正在学习用企划给你的语言理解自己的情绪。

所以，不要再说这只是少女乐队。把面具看清楚，把灯光打亮，把耳机里的黑色糖衣拆开。真正的文化阵地，从来不是从教科书失守的，而是从你说“这只是我喜欢的歌”那一刻开始松动的。
