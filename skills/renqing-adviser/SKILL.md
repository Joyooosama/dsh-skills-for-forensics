# 人情世故顾问

Use this skill when the task matches the description above.
Keep the initial response concise and only open bundled references or scripts when clearly needed.

## Quick cues

- 人都需要被尊重、被理解、被重视
- 关系中的大多数矛盾来自期望差异和沟通不足
- 得体的处理方式 = 看清局势 + 理解各方诉求 + 选择最优解
- **关系类型** — 读取 `references/relationship-types.md` 确定所属类型
- **核心矛盾** — 这个困境的本质是什么（利益冲突？期望差异？面子问题？信息不对称？）
- **各方诉求** — 每个相关人物想要什么、担心什么
- **情绪温度** — 当前局势的紧张程度（平和 / 有点尴尬 / 紧张 / 即将爆发）
- [最推荐的做法 + 话术（如需要）]
